## 发布与内容边界

本仓库采用无需构建的 HTML/CSS/JavaScript，由 GitHub Pages 从 main 分支根目录发布。`.nojekyll` 用于直接发布静态文件。收藏保存在当前浏览器。

题录与证据说明来自「梳理顶刊区块链论文」核验目录，网站不代表所有论文均已完成全文审读，也不自动更新后续发表状态。接收日期未公开的记录不归入年份统计。此前版本保留在 Git 历史中。
