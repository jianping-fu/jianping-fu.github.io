## 发布与更新

本仓库采用无需构建的 HTML/CSS/JavaScript，由 GitHub Pages 从 main 分支根目录发布。`.nojekyll` 用于直接发布静态文件。

`assets/catalogue.json` 为结构化题录；`downloads/` 保留完整目录与历次核查记录。收藏仅保存在当前浏览器，不跨设备或域名同步。

## 内容边界

题录、日期、状态、中文研究焦点与证据说明沿用「梳理顶刊区块链论文」原始目录，网站不代表全部论文均已完成全文审读，也不自动更新后续发表状态。已接收但接收日期未公开的文献不归入任何年份；社论不当作原创实证或理论研究。

此前的个人主页源文件仍可通过 Git 历史恢复。原 Sites 网站独立保留，本仓库不包含其访问控制、凭证或部署身份文件。
