# 链上文献 · Chainlit

公开网站：https://jianping-fu.github.io/

区块链与加密资产研究文献库：覆盖指定 19 本期刊，收录 161 篇主目录文献与 7 篇边界相关文献，按 13 个研究主题组织。目录快照为 2026-10-27。

## 功能

- 标题、作者、关键词与 DOI 搜索
- 主题、期刊、年份、发表状态组合筛选
- 主题及时间排序、分页与题录详情
- 研究图谱、期刊索引与浏览器本地收藏
- 原始 Excel、BibTeX、Markdown 下载及当前筛选结果导出

## 发布与更新

本仓库采用无需构建的 HTML/CSS/JavaScript，由 GitHub Pages 从 main 分支根目录发布。`.nojekyll` 用于直接发布静态文件。更新文件并推送 main 后，GitHub Pages 会重新发布。

`assets/catalogue.json` 为结构化题录；`downloads/` 保留原始目录文件。收藏仅保存在当前浏览器，不跨设备或域名同步。

## 内容边界

题录、日期、状态、中文研究焦点与证据说明沿用「梳理顶刊区块链论文」原始目录，网站不代表全部论文均已完成全文审读，也不自动更新后续发表状态。已接收但接收日期未公开的文献不归入任何年份。

此前的个人主页源文件仍可通过 Git 历史恢复。原 Sites 网站独立保留，本仓库不包含其访问控制、凭证或部署身份文件。
